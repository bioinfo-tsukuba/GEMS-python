## Failures encountered and fixes

| Observation / reproduction | Cause | Fix and verification |
| --- | --- | --- |
| A legacy simple-task JSON penalty restored as a string | The task saved its penalty as a JSON string, then assigned that string on loading | Shared typed serialization and a legacy adapter. Verified concrete penalties and calculated values |
| State settings disappeared; restoring ReactionState lacked candidates. Legacy State.from_dict also modified input | Legacy State.to_dict saved only the class name; from_dict called the constructor after pop | Saved all attributes and concrete types; restored without constructors. Missing legacy settings cause path-specific errors. Repeated restoration leaves input unchanged |
| IPSExperiment.from_json raised unexpected experiment_name | The derived constructor was called with base dataclass arguments | Restored saved attributes directly. Verified subtype preservation and unchanged constructor call count |
| Legacy State index was absent with multiple identically named States | Saved data could not uniquely determine the index | Added path-specific rejection and a reproduction test instead of guessing |
| CyclicalRestPenalty tuple became a list | JSON arrays alone could not distinguish tuples | Verified restoration using new tuple metadata and legacy type annotations |
| Empty Pandas histories differed in new acceptance tests | An Arrow table with zero columns loses RangeIndex column information | Saved supplementary information for empty RangeIndex columns. Verified equality across both formats and all managers |
| Experiment-side completed status did not update after resuming a single-machine run | Manager and Experiment TaskGroups were restored independently | Saved shared references. Verified resumed runs, mismatch detection after removing sharing, and loading JSON with sorted keys |
| Existing legacy test raised KeyError when editing to_dict keys directly | The new format changed the top-level structure | Used explicit legacy input to verify reader compatibility. Saved current_task=None is not regenerated |
| New test could not find penalty name linear | The test used the wrong existing factory argument | Changed to class name LinearPenalty. All penalty acceptance tests passed |
| Full-suite UUID and rendering API exceptions | IPS default UUID was an import-time UUID object; Matplotlib used the old cm.get_cmap | Generated per-instance string UUIDs and used plt.get_cmap. The original five errors disappeared; PNGs were also loaded and checked |

## Practical limits

Verification covers virtual experiments and resuming with the same inputs,
observer and solver settings. It does not cover hardware communication or
restoration of external-service state. State settings, subtypes and shared
references lost in legacy JSON cannot be recovered later. See the
[persistence specification](../persistence.md) for supported types, loading
prerequisites, the to_dict structure change and legacy-format constraints.
